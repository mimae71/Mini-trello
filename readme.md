# 🗂️ Mini Trello

Mini application type Trello pour manipuler le **drag & drop** en JavaScript vanilla et gérer des listes de tâches.

---

## 🎯 Objectifs pédagogiques

- Manipuler le **drag & drop** natif en JavaScript
- Structurer une petite application en JS (DOM, événements, data)
- Gérer la **sauvegarde des données** avec `localStorage`
- Ajouter des fonctionnalités d’édition et de suppression de tâches
- Gérer un **thème clair / sombre**
